## 核心修复

| 编号 | 已实现行为 |
|---|---|
| C01 | 初始化参数失败保留插件声明，重试时不重复登记内置插件；成功初始化后关闭注册窗口。 |
| C02 | 初始化期间的身份、用户属性和位置调用进入有界缓冲，按调用顺序恢复；采集关闭时不回放行为事件。 |
| C03 | 首次 App 显示前的 track / 用户属性等待本次会话；其后的身份/位置操作一并保序。首次显示前连续设置身份不会提前产生 VISIT。 |
| C04 | 按已清理空字段的上报事件恢复缓存，不再要求被省略的公共字段存在；继续检查事件类型、事件专属必需字段、序列化及字段白名单。 |
| C05 | 以业务行为不变为前提插桩；函数引用、条件返回函数、不安全组件选项保持原样并告警。保留显式函数全部参数、this、返回/抛错；探针异常隔离，不再次求值动态业务绑定，不复制组件选项或触发额外 getter。 |
| C06 | 应用版本取 appVersion，系统版本优先 osVersion；读取实际包字段/hostPackageName，Android/iOS 必要时通过 Native.js 获取包标识，失败时省略，不能使用 DCloud appid。 |
| C07 | idMapping 关闭时清理恢复身份的 userKey，并持久化清理结果；新事件不再携带历史 userKey。已缓存上报事件仍按 C04 原样恢复。 |
| C08 | 自动来源覆盖进入、返回、替换和 tab 切换；同页后台恢复保持原来源，onLoad query 与显式来源保留快照。 |
| C09 | 接通页面配置标题和成功的 setNavigationBarTitle 更新，保留 gioPageTitle 覆盖；迟到回调不写已卸载页面，采集失败不阻断业务回调。 |
| C10 | App show/hide 更新未来事件的前后台状态。 |
| C11 | 普通发送与到期重试共用最多 3 个上传槽位。 |
| C12 | 按接收时采集状态回放生命周期，按顺序处理恢复采集，避免初始化中恢复采集重复 VISIT/PAGE。 |
| C13 | demo 初始化与采集开关页面共用 enabled 状态；重复设置合法值按成功处理。 |

C05 会缩小自动采集范围：`@click="save"`、`ready ? save : cancel` 等会跳过，而不是由 SDK 强制执行函数。动态 data-* 从宿主 dataset 获取，动态 picker range 回退所选下标。示例与文档已更新这一边界；不要为了增加采集而批量改写客户业务模板。

## 追加复审修复（2026-09-08）

| 问题 | 已实现行为与回归覆盖 |
|---|---|
| TypeScript 包装的函数引用被误改写 | 识别 `save!`、`save as Handler`、`save satisfies Handler`、泛型引用及其组合，保持原模板，跳过采集。用与真实 Vue Vite 插件一致的 TypeScript 模板解析配置，对照原始和处理后 listener 的业务调用及全部参数。继续严格遵守 C05。 |
| 断网期间耗尽重试并删除事件 | 将连接状态与协议中的网络类型分开。明确离线时保留队列、暂停发送及到期重试，恢复连接后继续；`UNKNOWN` 不等于离线。离线期间的网络失败不额外消耗重试次数，迟到查询不能覆盖较新的网络通知。覆盖冷启动离线持久化、重连、最后一次重试及查询竞态。 |
| CommonJS Vite 配置无法静态加载 ESM 工具 | 接入示例和 demo 改为异步配置内动态导入 SDK 插件，保留 ESM 项目的静态导入方式。npm、uni_modules 两个最终压缩包均在仓库外安装，并分别通过真实 Vite 对 CommonJS / ESM 配置的加载及转换检查。 |
| 初始化业务缓冲占满后丢失关键生命周期 | 业务/状态调用与生命周期各有最多 50 项、256 KiB 的有界缓冲，按统一序号合并回放；总上限为 100 项、512 KiB。业务缓冲满后，App / Page 生命周期仍可进入独立缓冲并建立会话，已接受的业务事件能继续上报。覆盖项数、字节上限和顺序。 |
| 同路由不同页面实例返回时来源错误 | 使用页面实例标识判断是否切换页面，正确更新自动来源；同一实例后台恢复仍保留来源。覆盖同路由多实例进入、返回和后台恢复。 |
| 后台切换身份或恢复采集丢失会话超时依据 | 新建会话时保留进入后台的时间；再次进入前台仍按该时间判断超时。覆盖身份切换、恢复采集、精确超时边界与实际事件序列。 |
| 恢复缓存后重试次数重新归零 | 从缓存中的 retryCount 继续计算重试预算；不同次数的事件分批发送，已超预算的历史事件不再发送。覆盖不同预算混合队列与队列排空。缓存事件仍遵守 C04，不要求已清理的空公共字段存在。 |
| 初始化快照改变属性值语义 | 在 JSON 快照前按既有规则归一化属性；初始化、等待首次显示和就绪阶段行为一致。覆盖 undefined、NaN、Infinity、有效/无效 Date、数组及调用后修改；采集关闭时不读取属性 getter。 |
